# Customer Loan Default Prediction with Decision Trees

## Project Overview
This project uses Decision Tree classification to analyze customer credit risk and predict whether a customer belongs to the good-risk or bad-risk category.

The project explores Decision Tree algorithms, splitting criteria, model visualization, and hyperparameter tuning.

## Dataset
- Dataset: German Credit Risk Dataset
- Source: Kaggle – German Credit Risk
- Target variable: Risk (Good / Bad)

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Project Implementation

1. Data loading and preprocessing.
2. Entropy and Information Gain calculations from scratch.
3. Gini Impurity and Gini Reduction calculations.
4. Recursive Decision Tree implementation.
5. Decision Tree training with maximum depth of 3.
6. Decision Tree visualization.
7. Overfitting analysis.
8. Hyperparameter tuning using GridSearchCV.
9. 5-fold cross-validation.

## Learning Outcomes
- Understanding Decision Tree algorithms.
- Comparing Entropy and Gini splitting criteria.
- Implementing tree-building logic from scratch.
- Understanding overfitting and model complexity.
- Applying cross-validation and hyperparameter tuning.

## Conclusion
This project demonstrates how Decision Trees can be used for customer credit-risk classification and provides practical experience in implementing and evaluating machine learning models.
